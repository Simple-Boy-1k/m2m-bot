# 🚀 M2M VC Joiner Bot

Telegram VC Joiner Bot with In-Bot Session Management.

---

### 💜 Deploy to Heroku

[![Deploy to Heroku](https://www.herokucdn.com/deploy/button.svg)](https://heroku.com/deploy)

---

### 🛠️ Setup:
1. Fork repository.
2. Click **Deploy to Heroku**.
3. Fill credentials (`API_ID`, `API_HASH`, `BOT_TOKEN`, `MONGO_DB_URI`, `OWNER_ID`).
4. Deploy and start bot on Telegram.
